# pybuild

> A full-featured static site generator written in Python.

**pybuild is currently under active development and has not reached 1.0 yet.** APIs, configuration, and features may change.

## About

pybuild is a Python-based static site generator for building complete static websites from content, templates, and assets.

## Features

* Markdown and content processing
* Templating
* Static asset handling
* Front matter and metadata
* Site configuration
* CLI-based workflow
* Extensible build system

## Status

🚧 **Pre-1.0 / Work in Progress**

pybuild is still under development. Expect breaking changes before the 1.0 release.

## Development

Clone the repository and install the development environment with [`uv`](https://docs.astral.sh/uv/):

```bash
git clone https://github.com/yourname/pybuild.git
cd pybuild
uv sync
```

Run the test suite:

```bash
uv run pytest
```
